A-102 · Revit Add In

Room finishes, edited like
a spreadsheet, committed like Revit.

A production quality Revit 2025/2026 add in (WPF + MVVM) that loads every room from the active model into an editable schedule. Architects bulk edit finishes, save and load templates, run validation and quality checks, review analytics, and push every change back to Revit in one single transaction, with an optional AI assistant proposing finishes for the rooms left blank.

FilteredElementCollector→editable grid (modeless WPF)→bulk edit / templates / QA→Review Changes→single transaction commit
Why it exists

The problem

Specifying finishes room by room in Revit means opening the Properties palette for one room at a time, editing the same four or five fields, closing it, and repeating, on a real project, hundreds of times. It's slow, and it's easy to miss a room or mistype a finish.

The approach

Collect every room once, edit all of them in one Excel like grid with search, filters and bulk actions, validate and preview the effect of every change, then commit them all to the model together, with a full audit log and an undo path before anything is written.

Architecture

Clean layers, one bridge to Revit

No Revit API calls live in the ViewModels. Because the window is modeless, every model read or write after the first load is marshalled onto Revit's own thread through a single ExternalEvent, the only door between the WPF UI and the live document.

Commands/ OpenRoomFinisherCommand — IExternalCommand: first room read + show window App/ RoomFinisherApplication — IExternalApplication: ribbon tab + button Revit/ RevitRequestRouter — generic IExternalEventHandler (UI ↔ Revit bridge) RevitWorker — IRevitWorker impl (Collect / ApplyChanges) RevitContext — singleton window + router + WPF Application guard RevitServices/ RoomCollectorService — FilteredElementCollector → RoomData RoomParameterService — BuiltInParameter map, units, read only handling RevitTransactionService — the single commit transaction ViewModels/ MainViewModel (orchestrator), RoomViewModel (dirty/undo), BulkEditViewModel · ReviewChangesViewModel · AnalyticsViewModel QualityReportViewModel · ApplyTemplateViewModel Services/ SearchService · TemplateService · BulkEditService · UndoService ChangeTrackingService · ExcelExportService · AnalyticsService QualityCheckService · AuditLogService · AiFinishService

Ceiling height is not a native Revit room parameter, it's resolved by a configurable parameter name, and left read only/blank rather than fabricated if the model has none. Units round trip through Revit's own value string parser, so mm, m, and feet inches all behave correctly. Charts use OxyPlot instead of a SkiaSharp based library, to avoid native binary conflicts inside Revit's shared AppDomain.

Feature set

Everything a finish pass needs, in one window

01

Editable grid

Every room, grouped by level then number. Finish columns are combo boxes, pick a default or type a custom value. Edited cells turn yellow and count toward "N modified rooms."

02

Search + level filter

Real time search by name, number, or department, combined with a level filter.

03

Bulk edit

Select multiple rows, choose a target field and value, apply to all of them at once, fifty clicks become one.

04

Templates

Save or load JSON finish templates, scoped to All / Selected / By Department, with a preview before anything applies.

05

Quality check

Flags duplicate numbers, duplicate names, empty finishes, casing inconsistencies, and fuzzy near duplicates like "Marble" / "Marbel." Scores the model 100 minus errors×5 minus warnings×1.

06

Analytics

Live finish distributions, counts, percentages, pie and bar charts, that update as you edit.

07

Excel export

Exports the currently visible (filtered) rows to a formatted .xlsx with a frozen, bold header and auto fit columns.

08

Review → commit

Validates, shows a before/after Review Changes window, then writes everything in one transaction and reports updated/failed counts, never a partial write.

AI Finish Assistant

Suggests. Never writes on its own.

AI Assist analyzes the selected rooms (or all of them) and proposes wall, floor, ceiling, and base finishes, filling in the empty ones and flagging existing finishes that don't suit a room's function, reusing the project's own finish palette for consistency. Works with Google Gemini or Anthropic Claude, direct HTTPS calls to each provider's REST API, deliberately without an SDK, to avoid adding another dependency inside Revit's process.

1

Pick a provider in AI Settings and paste a matching API key, a Google key for Gemini, an sk-ant-… key for Claude.

2

Run AI Assist on up to 80 rooms. Each suggestion comes back with a short reason, hygiene, moisture, durability, traffic, or acoustics.

3

Every suggestion appears in an approval window with a checkbox, current value → suggested value → reason. Untick anything you don't want.

4

Accepted changes land in the grid as ordinary edits, then go through the same validation → Review → single transaction commit as everything else. Nothing is written to Revit by the AI directly.
